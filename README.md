# gareldd

Личный сайт на React, TypeScript и Vite. Порядок главного раздела: случайное приветствие → крупный 3D-портрет Minecraft по торс → текст обо мне. Интерфейс использует локальный Pixeloid Sans; в шапке стоит прежний логотип gareldd. Соцсети представлены квадратными плитками. Плитка с логотипом G.D.Z. Server открывает отдельное модальное окно поверх сайта.

## Запуск

Нужен Node.js 22.12+ (для тестов с TypeScript без отдельного компилятора — Node.js 24).

```sh
npm install
npm run dev
```

Открой адрес из терминала, обычно `http://127.0.0.1:5173`.

```sh
npm run build
npm run preview
npm test
```

`build` проверяет строгий TypeScript и создаёт `dist`. На статический хостинг загружай содержимое `dist`, а не исходный `index.html`. Путь ресурсов задаётся через BASE_PATH; серверные API не требуются. Используемые ресурсы хранятся только в `public/assets`; старые HTML, CSS, JavaScript, дубли и неиспользуемые иконки вынесены из проекта.

## Публикация на GitHub Pages

Репозиторий: `gareldd/grld.github.io`. Сайт: `https://gareldd.github.io/grld.github.io/`.

В настройках репозитория открой **Settings → Pages → Build and deployment → Source** и выбери **GitHub Actions**. После коммита в `main` файл `.github/workflows/deploy.yml` установит зависимости через `npm ci`, соберёт сайт и опубликует только содержимое `dist`. Перезапустить публикацию можно во вкладке **Actions → Deploy website to GitHub Pages → Run workflow**.

Для GitHub Pages сборка использует `BASE_PATH=/grld.github.io/`. При локальном запуске путь по умолчанию — `/`.

`src` содержит код и настройки сайта, `public` — используемые статические ресурсы, `tests` — проверки анимации и загрузки скина, `docs` — исходное техническое задание. `node_modules`, `dist`, журналы, файлы окружения и кэш TypeScript исключены из Git.

## Скин и настройки

Имя Minecraft, модель Slim, длительность появления и приветствия, чувствительность головы/торса/камеры находятся в `src/config/site.ts`. `src/lib/animationTimeline.ts` вычисляет последовательность: появление 0–500 мс, два взмаха 500–2000 мс, затем слежение за курсором. Последние 260 мс жеста отведены возвращению руки. Отсчёт начинается после первого кадра с загруженным скином; скрытая вкладка и сцена вне экрана приостанавливают отсчёт.

Текст обо мне — `src/config/about.json`, ссылки на соцсети, варианты приветствий и кадрирование портрета (`PORTRAIT`) — `src/config/site.ts`. Проекты G.D.Z. Server и SLH, их описания, авторский текст и ссылки — `src/config/projects.ts`; общее окно проекта — `src/components/ProjectDialog.tsx`.

Для SLH используется предоставленный логотип `SLHmain.png`; ссылки на Telegram, Discord и GitHub взяты с [официального сайта SLH](https://slhmc.github.io/). Логотипы обоих проектов расположены по центру окна; авторский текст о SLH сохранён дословно.

Telegram открывает отдельное меню с основным каналом, приваткой Tribute и каналом об ИИ. Ссылки находятся в `TELEGRAM_CHANNELS` в `src/config/site.ts`. Приватка стоит посередине и выделена вращающимся градиентом `#CD491E` / `#4C1B0A` с пиксельной Bayer-текстурой. На телефоне три пункта располагаются вертикально; приватка остаётся вторым пунктом. Анимация отключается при уменьшении движения. Меню закрывается крестиком, Escape или кликом снаружи.

Скин запрашивается при новом посещении с `https://mc-heads.net/skin/gareldd`. Это настоящая текстура модели skinview3d, с внешними слоями и руками шириной 3 пикселя. Локальной постоянной копии скина нет. В рамках одной открытой страницы успешная текстура хранится в памяти, чтобы повторное монтирование React не вызывало лишних запросов.

MCHeads кэширует скины примерно на 24 часа; браузер и CDN тоже могут кэшировать ответ. Смена скина появится после обновления кэшей сервиса и нового посещения/перезагрузки страницы, без изменения кода. Мгновенное обновление не гарантируется. Документация сервиса: [MCHeads](https://mc-heads.net/). Библиотека: [skinview3d](https://github.com/bs-community/skinview3d).

При ошибке сети показана кнопка повторной загрузки; при отсутствии WebGL — объяснение. Остальные разделы доступны независимо от 3D. На сенсорных устройствах персонаж остаётся в спокойной позе после приветствия. При настройке уменьшения движения жест и параллакс отключены.

## Проверка вручную

- Дождись скина: появление должно начаться только после его загрузки, затем один жест рукой и слежение.
- Перемести курсор в четыре угла окна: голова смотрит в ту же сторону; торс и камера поворачиваются слабее. Уведи курсор из окна — поза возвращается к исходной.
- Проверь 1920×1080, 1366×768 и мобильную ширину: персонаж показан крупным планом от головы до торса, текст идёт ниже.
- Для медленной/ошибочной сети задержи или заблокируй `mc-heads.net/skin/gareldd` в инструментах браузера и перезагрузи страницу; проверь загрузку и повторную попытку.
- Прокрути сцену за пределы экрана или переключи вкладку: она должна приостановиться, а при возвращении продолжиться без повторного приветствия.
- Нажми логотип G.D.Z. Server: поверх сайта откроется окно с прежним описанием и ссылкой на проект. Закрой его крестиком, Escape или кликом снаружи; фокус должен вернуться к плитке. Проверь открытие клавишей Enter и переход между элементами клавишей Tab.
- Перезагрузи страницу: приветствие выбирается заново без повторения предыдущего, когда доступен sessionStorage.

## Движение и освещение

Спокойная idle-анимация реализована отдельно от управления взглядом: дыхание, небольшое покачивание корпуса и движения рук плавно включаются после приветственного жеста. Визуальный ориентир — [HeroIdleAnimation в Millida Launcher](https://github.com/millida/launcher/blob/main/src/vendor/mine3d/core/skin-animations.ts); исходный код лаунчера не переносился. Параметры собственной анимации — `IDLE` в `src/config/site.ts`.

Пока курсор находится на странице, персонаж сохраняет направление взгляда даже без движения мыши. После ухода курсора или потери фокуса взгляд удерживается ещё 10 секунд, затем плавно возвращается к центру. Для проверки уведи курсор из окна и дождись завершения задержки.

Сцену освещают основной, заполняющий и контровой источники. Нижняя часть портрета плавно исчезает через CSS-маску; за приветствием добавлено мягкое свечение.

Кадрирование учитывает ширину сцены, наклон головы и поднятую руку. На узких экранах камера даёт больше места во время приветствия, затем плавно приближается к портрету. Параметры — `PORTRAIT`, расчёт расстояния — `portraitDistance`.

Приветственный жест — два взмаха над головой: быстрый подъём руки, два отчётливых маха и плавное возвращение к слежению в 2000 мс. Корпус слегка наклоняется один раз и возвращается, без подскоков и качания в такт руке. Сцена поднята ближе к приветствию с сохранением пространства для головы.
